One joke about crypto and trading life: a stop-loss set to protect the trader's money, triggered so fast it now protects someone else's money.

> I set a stop-loss to protect my money. It triggered so fast it now protects someone else's money.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
